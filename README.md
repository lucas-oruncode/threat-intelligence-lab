# 🛡️ Threat Intelligence Lab

Este repositório contém estudos de caso práticos de investigação de ameaças cibernéticas, simulando cenários reais de incidentes.

## 🎯 Objetivo

Desenvolver habilidades em:
- Análise de IOC
- Threat Intelligence
- Correlação de dados
- Investigação de incidentes

## 📁 Casos

| Caso     | Tipo                          | Descrição                                      |
|----------|-------------------------------|-----------------------------------------------|
| Case 001 | Phishing + C2                 | Malware via download por engenharia social     |
| Case 002 | Brute Force + Root + C2       | Comprometimento de servidor via SSH e execução de payload |
